### Executar o sistema bancário

Requisito: Python 3.10 ou superior, sem dependências externas.

```bash
cd desafios/sistema-bancario-funcoes
python sistema_bancario.py
```

Para executar os testes, na mesma pasta:

```bash
python -m unittest -v
```

A solução inclui 15 testes e evidências de execução. O saldo, o histórico e o contador de saques são mantidos em memória durante a execução.
